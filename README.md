# Nihar Ramoliya — Personal Portfolio

A modern, fast, and fully responsive personal portfolio website designed to showcase my skills, projects, and professional background. Built from scratch with core web technologies to ensure optimal performance and a clean, maintainable codebase.

## ✨ Features

- **Fully Responsive Design**: Fluid layout optimized for mobile, tablet, and desktop viewing.
- **Modern UI/UX**: Clean, professional design with a focus on readability and content presentation.
- **Smooth Animations**: Engaging scroll-reveal animations powered by the Intersection Observer API.
- **Section Navigation**: Seamless smooth scrolling between About, Skills, Projects, and Contact sections.
- **Mobile-Friendly Navigation**: Custom, interactive hamburger menu for smaller screens.

## 🛠 Tech Stack

- **HTML5**: Semantic markup for enhanced accessibility and SEO.
- **CSS3**: Custom styling, CSS Variables, Flexbox/Grid layouts, and responsive media queries.
- **Vanilla JavaScript**: Efficient DOM manipulation and scroll event handling without heavy external libraries.

## 💻 Local Setup & Execution

To run this project locally, simply follow these steps:

1. **Clone the repository:**
   ```bash
   git clone https://github.com/niharr05/Portfolio.git
   ```

2. **Navigate into the directory:**
   ```bash
   cd Portfolio
   ```

3. **Run the application:**
   Simply double-click the `index.html` file to open it in your default web browser, or use a tool like VS Code Live Server for hot reloading. No complex build steps or dependencies required!

## 🌍 Deployment on GitHub Pages

This website is structured to be easily hosted for free using **GitHub Pages**:

1. Push your code to a remote GitHub repository.
2. Navigate to your repository's **Settings** tab.
3. In the left sidebar, click on **Pages**.
4. Under the **Build and deployment** section, select **Deploy from a branch**.
5. Set the branch to `main` and the folder to `/ (root)`.
6. Click **Save**. Your site will be built and available via a live URL within minutes.
